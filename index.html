01 · основы

Что такое нейросеть

Нейросеть — это не копия мозга и не магия. Это математическая функция с большим количеством настраиваемых чисел. Она не «понимает» мир — она подбирает числа так, чтобы на знакомых примерах выдавать правильные ответы, и надеется, что на новых примерах тоже сработает.

Чем это отличается от обычной программы

Обычная программа: человек пишет правила, программа применяет их к данным и выдаёт ответы. Нейросеть переворачивает процесс: мы даём данные и правильные ответы, а правила (числа-веса) сеть находит сама. Никто не писал ей «у кошки усы и треугольные уши» — она вывела это из тысяч фотографий.

классика: правила + данные → ответы
нейросеть: данные + ответы → правила

Из чего она собрана

  • Нейрон — крошечная ячейка: складывает входные числа с весами и пропускает сумму через функцию активации.
  • Слой — группа нейронов, работающих параллельно. Входной слой принимает данные, скрытые слои их преобразуют, выходной даёт ответ.
  • Веса — числа на связях между нейронами. Именно они «знают» всё, что знает сеть. Обучение = подбор весов.
  • Смещение (bias) — личная добавка каждого нейрона к сумме, сдвигает его порог срабатывания.

Зачем веса разных знаков

Положительный вес говорит «этот признак — за», отрицательный — «против». Нейрон «загорающийся при усах и против при клюве» — уже детектор кошки.

Зачем функция активации

Без неё любая сеть, сколько бы слоёв ни было, схлопывается в одну линейную формулу. Нелинейность (σ, tanh, ReLU) позволяет выучивать кривые границы и сложные закономерности — например, XOR.

Почему слоёв много

Каждый слой строит признаки из признаков предыдущего: пиксели → края → текстуры → части → объекты. Глубина = иерархия абстракций, отсюда название «глубокое обучение».

03 · как сети учатся

С учителем, без учителя и между ними

Обучение — это всегда одно и то же: сеть делает предсказание, мы измеряем ошибку числом (функция потерь, loss) и чуть-чуть подправляем каждый вес в сторону уменьшения ошибки. Повторить миллион раз. Разница между подходами — откуда берутся «правильные ответы».

с учителем Supervised learning

У каждого примера есть метка: фото → «кошка», письмо → «спам», квартира → цена. Метки ставят люди (разметчики) — дорого, но точно. Сеть сравнивает свой ответ с меткой и учится.

  • Классификация: спам/не спам, диагноз, тон отзыва.
  • Регрессия: цена, температура, спрос — любое число.
  • Так дообучают LLM на диалогах «вопрос → хороший ответ» (SFT).

без учителя Unsupervised learning

Меток нет — сеть сама ищет структуру в данных: похожие объекты в кучки (кластеризация), компактное представление (автоэнкодер), выбросы (аномалии).

  • Сегментация клиентов без заранее заданных групп.
  • Поиск странных транзакций и брака на заводе.
  • Self-supervised — хитрый подвид: метки делают из самих данных. «Спрячь следующее слово и угадай его» — так предобучают все LLM на триллионах токенов без единого разметчика.

Градиентный спуск и backprop — механика чуда, по шагам

1 · forward

Прогоняем пример через сеть слева направо. Получили ответ, например 0.73, а правда — 1.

2 · loss

Ошибка — число: насколько ответ далёк от правды. Для «да/нет» обычно бинарная кросс-энтропия: чем увереннее сеть ошибается, тем больше штраф.

3 · backward

Обратный проход: по правилу цепочки вычисляем, как каждый вес повлиял на ошибку — его градиент. Ошибка «раздаётся» назад по слоям пропорционально вкладу.

4 · шаг

Каждый вес сдвигаем против его градиента: w ← w − lr·∂L/∂w. Learning rate (lr) — размер шага. Это спуск с горы в тумане: щупаем склон ногой и делаем маленький шаг вниз.

Один проход по всему датасету = эпоха. Данные едят пачками (батчами) — так梯度 шумнее, но обучение быстрее. Слишком большой lr — перепрыгиваем долину; слишком маленький — учимся вечность. Переобучение — когда сеть вызубрила тренировочные примеры, но проваливается на новых; лечится разделением train/test и регуляризацией.

04 · зрение

Свёрточные сети: как машина видит

Фото 1000×1000 — это 3 миллиона входов. Полносвязный слой на миллион нейронов потребовал бы 3 триллиона весов. CNN решает проблему красиво: маленький фильтр 3×3 (всего 9 весов!) скользит по всей картинке и ищет один узор везде. Кошка в углу и кошка в центре — один и тот же фильтр.

Свёртка

Окно 3×3 умножается на ядро почленно, произведения складываются — одно число карты признаков. Сдвинули окно (stride) — повторили. Ядро «вертикальный край» подсветит все вертикальные границы изображения.

Pooling

Уменьшение карты: из каждого блока 2×2 берём максимум. Картинка в 4 раза меньше, главное survives. Сеть перестаёт зависеть от точного положения узора — сдвиг на пиксель не страшен.

Иерархия признаков

Слой 1: края и пятна. Слой 2: углы, текстуры. Слой 3: глаза, колёса, буквы. Глубже — целые объекты. Каждый следующий слой свёртывает карты предыдущего: абстракции из абстракций.

05 · память

Рекуррентные сети: чтение по слову

«Собака укусила человека» и «Человек укусил собаку» — одинаковые слова, разный смысл. Порядок важен, а обычные сети его не видят. RNN читает последовательность по шагам и после каждого слова обновляет скрытое состояние h — вектор-«память» о прочитанном: hₜ = tanh(Wx·xₜ + Wh·hₜ₋₁ + b). Их часто по ошибке зовут «рекурсивными»; рекурсивные (RecursiveNN) работают по деревьям разбора — редкий зверь, здесь речь о рекуррентных.

Одна сеть, много шагов

Развёрнутая RNN — это одна и та же ячейка, применённая к каждому слову. Веса Wx и Wh общие для всех шагов: сеть учится «как обновлять память», а не отдельные правила для каждой позиции.

Затухающий контекст

Память перезаписывается на каждом шаге, и начало длинной фразы «размывается» — испорченный телефон из матриц. Градиенты при обучении через 100 шагов затухают до нуля. LSTM/GRU добавляют ворота: «запомнить», «забыть», «показать» — и держат контекст дольше.

Почему уступили Transformer

RNN обязана читать строго по очереди — нельзя распараллелить. Attention смотрит на любое слово напрямую, без цепочки пересказов. Быстрее обучение, дальше контекст. RNN остались в нишах: датчики, стриминг, крошечные модели.

06 · состязание

GAN: фальшивомонетчик против эксперта

2014 год, Ян Гудфеллоу: а что если тренировать две сети против друг друга? Генератор G превращает случайный шум в данные и никогда не видит настоящих примеров. Дискриминатор D видит и настоящие, и подделки, и учится их различать. G учится обманывать D, D — не обманываться. Единственная «разметка» — вердикт эксперта. В равновесии подделки неотличимы: D угадывает с вероятностью монетки, 50%.

Цикл тренировки

  • Шаг D: показать пачку настоящих (метка 1) и пачку свежих подделок (метка 0), обновить веса D по ошибкам.
  • Шаг G: сделать подделки, спросить D, и обновить веса G так, чтобы D чаще говорил «настоящее». Градиент течёт через D в G — эксперт невольно учит фальшивомонетчика.
  • Повторять. D не должен побеждать слишком сильно (G не получает полезного сигнала) и не должен проигрывать (сигнал теряет смысл).

Болезни и применение

  • Mode collapse: G находит одну картинку, которая всегда обманывает D, и штампует только её. Разнообразие умирает.
  • Нестабильность: две сети тянут одеяло — loss скачет, это нормально для GAN.
  • Применение: лица (thispersondoesnotexist), апскейл старых фото и игр, перенос стиля, синтез данных для обучения, реставрация. В большой генерации GAN вытеснены диффузией, но GAN делают картинку за один проход — они быстрее.

07 · большие языковые модели

ChatGPT, Claude, Qwen: что внутри

Сюрприз: внутри у всех одно и то же — Transformer (2017, статья «Attention Is All You Need»), а точнее его decoder-only разновидность. Модель решает одну задачу: «по предыдущим токенам предскажи следующий». Всё остальное — рассуждения, код, переводы — эмерджентные навыки этой задачи на гигантском масштабе.

Путь текста через LLM, слой за слоем

1 · токенизация

Текст режется на токены — кусочки слов (BPE). «нейросети» может стать «нейро»+«сети». Каждому токену — номер из словаря на ~100–250 тысяч штук.

2 · эмбеддинги

Номер → вектор из тысяч чисел, «смысловые координаты» токена. Плюс информация о позиции (обычно RoPE — поворот векторов на угол, зависящий от места).

3 · N блоков

Десятки-сотни одинаковых блоков: self-attention (слова обмениваются контекстом) + FFN (каждый токен «думает» сам). Вокруг — остаточные связи и LayerNorm, чтобы сигнал не терялся в глубине.

4 · logits → токен

Последний вектор → оценки (logits) для всех токенов словаря → softmax в вероятности → выбор (сэмплирование). Выбранный токен дописывается ко входу — и цикл повторяется. Это авторегрессия.

Внимание в двух словах: каждый токен делает три вектора — Query («что я ищу»), Key («что у меня есть»), Value («что я передам»). Оценка совместимости = Q·K/√d, softmax превращает оценки в веса, и токен забирает взвешенную сумму Value других. Много «голов» смотрят с разных сторон: одна следит за грамматикой, другая — за тем, к кому относится «он». В decoder-only стоит причинная маска: слово видит только прошлое, не будущее.

Три механизма LLM — потрогай каждый

Упрощённая BPE-подобная нарезка: частые слова целиком, длинные — на куски (продолжения помечены ##). ID — игрушечные, но принцип настоящий: модель видит числа, а не буквы. Заметь: пробелы и знаки препинания — тоже токены, а русский текст «дороже» английского по токенам.

Кликни слово — увидишь, на кого оно «смотрит» (весаAttention, причинная маска: только назад). Веса — учебная иллюстрация, рассчитанная для наглядности.

Вероятности следующего токена · softmax(logits / T)

T→0: модель всегда берёт максимум (скучно и уверенно). T↑: распределение flattening, растёт шанс редких слов (творчество и бред). Настоящие LLM делают ровно это — миллиарды параметров ради одной таблицы вероятностей. Игрушечные logits, настоящий softmax и сэмплирование.

Как их выращивают

1. Предобучение (self-supervised): триллионы токенов, задача «следующий токен». 2. SFT: тысячи идеальных диалогов с учителем. 3. RLHF/DPO: люди сравнивают ответы, модель учится предпочтениям. Отсюда «полезность» и отказ от вредных запросов.

Инженерные трюки

MoE: вместо одной FFN — десятки «экспертов», роутер включает 2 из них на токен: параметров много, вычислений мало. GQA/MLA: общий KV для групп голов. KV-кэш: не пересчитывать прошлое при каждом новом токене. RoPE: позиции через повороты.

Границы и галлюцинации

LLM — предсказатель продолжений, а не база фактов: правдоподобное ≠ правдивое. Контекстное окно ограничено (хоть и до миллионов токенов). Знания застыли на дате обучения — свежие факты дают через поиск (RAG) и инструменты.

08 · песочница

Собери и обучи свою нейросеть

Три входа A, B, C (каждый 0 или 1) и задача-операция: OR, AND или XOR. Сеть должна выдавать правильный бит для всех 8 комбинаций. Ты выбираешь архитектуру и гиперпараметры — и наблюдаешь настоящий градиентный спуск: веса на связях, сигналы в нейронах, падающую ошибку. Никаких заготовленных анимаций — каждый кадр считается заново.

Спойлер-эксперимент: OR и AND сеть выучит даже без скрытых слоёв. XOR — никогда: он линейно неразделим, и доказательство этого (Минский и Пейперт, 1969) заморозило нейросети на 15 лет. Добавь хотя бы один скрытый слой — и увидишь, как глубина решает то, что ширина не может.

Связь: толщина = |вес|, голубой = «+», розовый = «−». Яркость нейрона = его активация на текущем входе A,B,C. Наведи на связь или нейрон — увидишь числа. Кликни строку таблицы — прогонишь эту комбинацию через сеть. Одна эпоха = forward+backward по всем 8 комбинациям (полный батч), выход — сигмоида, loss — бинарная кросс-энтропия.

Эксперимент 1

XOR без скрытых слоёв: ошибка застрянет около 0.69, точность 4–6 из 8. Добавь слой из 3–4 нейронов — и за пару сотен эпох будет 8/8.

Эксперимент 2

Что эффективнее для XOR: 1 слой × 6 нейронов или 3 × 3? Сравни число эпох и параметров. Глубже — не всегда лучше на простых задачах.

Эксперимент 3

lr = 0.02 против lr = 0.9: понаблюдай за графиком. Большой шаг ускоряет, но может колотить ошибку; ReLU на 2-нейронных слоях часто «умирает» — все нули.

Карманный словарь

Эпоха / батч

Эпоха — один полный проход по датасету. Батч — пачка примеров, обрабатываемая за один шаг обновления весов.

Learning rate (lr)

Размер шага, которым веса двигаются против градиента. Главный гиперпараметр: 0.001–0.1 для больших сетей, больше — для игрушечных.

Градиент / backprop

Градиент — направление самого крутого роста ошибки по каждому весу. Backprop — алгоритм, вычисляющий все градиенты за один обратный проход по правилу цепочки.

Loss (функция потерь)

Число «насколько сеть ошиблась». MSE для чисел, кросс-энтропия для классов. Обучение = минимизация loss.

Переобучение

Сеть вызубрила тренировочные примеры и проваливается на новых. Лечение: больше данных, train/test-разделение, dropout, ранняя остановка.

Словарь, часть 2 · и куда расти

Токен / эмбеддинг

Токен — кусочек текста, единица входа LLM. Эмбеддинг — вектор-«координаты смысла» токена; близкие смыслы — близкие векторы.

Инференс

Применение обученной сети (без обновления весов). Всё, что делает ChatGPT при ответе тебе, — инференс.

Параметры / веса

Все настраиваемые числа сети: веса связей + смещения. «7B» у Llama — 7 миллиардов таких чисел.
